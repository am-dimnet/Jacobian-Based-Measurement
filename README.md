# Reproducible code and evidence for TIM-26-07850

**Jacobian-Based Measurement of Local Input-Equivalent Sensitivity of ECG Encoders Under Federated Update Perturbations**

This is the English-only reproducibility package for the manuscript audited on 22 September 2026. It includes scientific source code, exact processed inputs, the selected raw waveform archive, retained checkpoints, predictions, probe energies, Monte Carlo curves, statistical analysis, figure-generation code, and the current LaTeX manuscript. No training or model evaluation was run to assemble this package.

## Scope

The controlled study comprises 24 training runs, 48 initial measurement jobs, 15 additional evaluations, and 3 matching-only bracket extensions. Their retained numerical outputs are included. Historical diagnostic results are separately identified: saved-prediction statistics and figures can be reconstructed, but missing original checkpoints and source-cache mappings prevent complete historical retraining replay. New training is not a reconstruction of the missing historical experiment.

Start with [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for the evidence boundaries, result-to-code map and portability changes. The data are nominal dataset voltages; the package does not establish a missing instrument-calibration chain.

## Environment

The recorded training environment is Linux x86_64, Python 3.12.3, PyTorch 2.8.0+cu128, and Tesla V100S GPUs. The full environment record is in `environment/`. The recorded direct scientific dependencies are pinned in `requirements.txt`. Do not install the full `pip_freeze.txt` blindly: it includes unrelated notebook packages and machine-local Conda build paths.

```bash
conda env create -f environment.yml
conda activate tim2607850
python -m pip install -r requirements-cuda.txt
python -m pip install -r requirements.txt
```

A CPU installation of PyTorch is sufficient for some retained-array postprocessing imports; training, HXV evaluation and physical-input evaluation require CUDA. The independent validation scripts require NumPy, not a GPU. Matplotlib is needed for figures. A TeX distribution with IEEEtran, or Tectonic, is needed to compile the manuscript and TikZ schematics. Exact GPU timing and bitwise identity across hardware/software stacks are not promised.

## Verify the package without running experiments

```bash
python scripts/verify_package.py
python validation/table_audit.py
python validation/numerical_audit.py
```

Run the integrity check from the preserved package, not from a modified workspace. The first command checks the SHA-256 manifest, English-language filename/text scan, Python syntax, and required resources. The latter commands compare the retained manuscript values and recompute statistics from saved arrays. The numerical audit includes all 140 historical paired-record bootstrap sets and can take time. These commands do not train a model or perform encoder inference. They only write validation reports.

## Recompute statistics and figures from retained outputs

Always use a separate workspace. The preparation helper uses independent APFS copy-on-write files on macOS when available, and ordinary copies elsewhere. It never uses external symbolic links and never starts an experiment.

```bash
python prepare_reproduction.py --mode analysis --destination /path/to/new-analysis
python scripts/reproduce.py --workspace /path/to/new-analysis --stage validate --execute
python scripts/reproduce.py --workspace /path/to/new-analysis --stage analysis --execute
python scripts/reproduce.py --workspace /path/to/new-analysis --stage figures --execute
```

Omit `--execute` to print commands only. Generated numerical reports go to `analysis/`, `supplement_round2/` and `legacy/analysis_outputs/` inside the workspace. Figure PDFs go to its `manuscript/` directory. No document-rewriting pipeline is invoked, so regenerating figures does not replace the final English article with an older draft. A cached historical bootstrap CSV is used by the legacy plotter; the independent numerical audit recomputes the bootstrap statistics and checks the cache.

The two method schematics have exact TikZ source:

```bash
cd /path/to/new-analysis/schematics
tectonic fig1_verified.tex
tectonic fig2_verified.tex
```

The remaining nine quantitative figures are generated by the `figures` stage. The authoritative publication PDFs are already included under `manuscript/`; regenerated files may differ in PDF metadata or font rendering while preserving the plotted data.

## Reproduce the controlled training and measurements

Prepare a fresh workspace with the exact input data but no training/measurement result directories:

```bash
python prepare_reproduction.py --mode training --destination /path/to/new-training
python scripts/reproduce.py --workspace /path/to/new-training --stage train --gpus 0,1 --execute
python scripts/reproduce.py --workspace /path/to/new-training --stage measure --gpus 0,1 --execute
```

The queues use the active Python interpreter. `--gpus 0` supports one GPU; it changes scheduling, not the job matrix. Training uses 30 rounds, FP32, fixed seed/split/reference conventions, and the exact method flags in the original matrix. Every child job logs its command and status. A child failure or incomplete queue makes the driver fail; do not continue with partial results. The queues refuse to overwrite a dispatched matrix or an existing experiment output directory. After a failed run, inspect logs and use a fresh workspace for a complete replay.

The training matrix is four native-cohort aggregation rules and four PTB allocation conditions, each with three seeds. The measurement matrix includes the primary MC match, structured covariances, gain controls, probe-count sweep, precision check, GPU profiling, 24 final trained states and 15 intermediate states. Profiling can create large transient traces: allow at least 12 GB free beyond the package and output workspace. Inspect the included environment and actual logs when interpreting timing.

Additional evaluations reuse the stored or newly reproduced Composite checkpoints:

```bash
python scripts/reproduce.py --workspace /path/to/new-training --stage additional \
  --gpus 0,1 --evaluation-out /path/to/fresh-additional-results --execute
python scripts/install_additional_outputs.py --workspace /path/to/new-training \
  --source /path/to/fresh-additional-results
python scripts/reproduce.py --workspace /path/to/new-training --stage analysis --execute
python scripts/reproduce.py --workspace /path/to/new-training --stage figures --execute
```

This schedules 15 evaluations followed by 3 full-reference bracket extensions. Initial 128-record failures are preserved separately from extended-bracket results and the exploratory 125-record stratum. The installation helper requires 18 completed jobs and refuses to overwrite existing results. The published table-validation script compares against the retained published numerical values; do not mistake differences from a genuinely new training run for a transcription failure. Compare new numerical reports under the stated conditions before making any new scientific claims.

## Rebuild the exact processed inputs

The package contains the accepted selected raw signals, not just a download link. Extract them to a new directory:

```bash
mkdir -p /path/to/new-raw
tar -xzf provenance/selected_raw.tar.gz -C /path/to/new-raw
python revision/server/rebuild_from_manifest.py --repo . \
  --raw-root /path/to/new-raw --manifest data/revision_v2/manifest.json \
  --out /path/to/new-rebuilt --workers 8
```

`analysis/source_rebuild_verification.json` records the earlier exact input reconstruction. The raw archive, source checksums, metadata, record IDs, exclusions and label rules are retained under `provenance/` and `data/revision_v2/`. Use the manifest to reproduce the accepted records; rerunning selection on an entire release is a different operation.

Physical-input references can be regenerated on Linux using the saved split and raw signals:

```bash
python supplement_round2/scripts/prepare_inputs.py . /path/to/new-physical-inputs /path/to/new-raw
python scripts/make_nonflat_input.py \
  --input /path/to/new-physical-inputs/interference_input.npz \
  --out /path/to/new-physical-inputs/interference_nonflat_input.npz
```

Compare every regenerated array with the included references before using it. The nonflat criterion is positive temporal variance in every lead, selected after the input audit; this is not a replacement for the full-reference result.

Source releases: PTB-XL v1.0.3, DOI `10.13026/kfzx-aw45`; ECG-arrhythmia v1.0.0, DOI `10.13026/wgex-er52`. The latter includes Chapman–Shaoxing and Ningbo sources. Source-data terms remain those of the original releases; this package does not grant a new data license or supply institutional ethics approval.
